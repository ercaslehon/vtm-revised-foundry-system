# Vampire: The Masquerade Revised - Foundry VTT System

Неофициальная система для Foundry VTT под Vampire: The Masquerade Revised / VtM v3 Revised и Demon: The Fallen.

Система ориентирована на домашние хроники, отдельные листы вампира и падшего, пошаговое создание персонажей, встроенные справочники и управляемую автоматизацию бросков, боя и сверхъестественных способностей.

## Статус проекта

- Package ID: `vtm-revised`
- Текущая версия: `11.0.30`
- Foundry VTT: minimum `13.347`, verified `14`
- Автор: `Ercaslehon`
- Тип проекта: fan-made / unofficial system
- Основной язык интерфейса: русский
- Дополнительная локализация: английский

## Установка через Foundry

В Foundry VTT открой:

```text
Setup -> Game Systems -> Install System -> Manifest URL
```

Вставь ссылку:

```text
https://raw.githubusercontent.com/ercaslehon/vtm-revised-foundry-system/main/system.json
```

Foundry прочитает `system.json` и скачает zip из GitHub Release.

## Основные возможности

### Лист персонажа

- Чарлист вампира.
- Отдельный чарлист демона.
- Чарлист NPC.
- Вампирский интерфейс с вкладками `Основное`, `Силы`, `Профиль`.
- Демонский интерфейс с вкладками `Основное`, `Преимущества`, `Апокалиптическая форма`, `Профиль`.
- Портрет персонажа и просмотр большого портрета по клику.
- Основные данные персонажа: имя, клан, поколение, сир, концепт, Натура, Маска, Путь или Дорога.
- Поддержка истории, целей, заметок, внешности, имущества и связей.

### Характеристики и способности

- Атрибуты: физические, социальные, ментальные.
- Способности по актуальному листу проекта: Таланты, Навыки, Знания.
- Специализации.
- Светящиеся точки характеристик.
- Лимиты точек по поколению.
- Корректное отображение расширенных значений для старших поколений.

### Ресурсы и трекеры

- Кровь.
- Сила Воли.
- Человечность / Путь / Дорога.
- Здоровье.
- Ограничения поколения: максимум черт, максимум крови, трата крови за ход.
- Опыт: редактируемое значение `Доступно` и журнал опыта во вкладке `Профиль`.
- Вера, постоянная и временная Мука демона.

### Журнал опыта

Во вкладке `Профиль` есть журнал опыта.

Поддерживается начисление опыта, трата опыта, ручная корректировка, причина операции, покупка или изменение, пользователь, дата операции, удаление записи и пересчёт итогов по журналу.

Для демона доступен мастер развития, который рассчитывает стоимость следующей точки Атрибута, Способности, Знания, Дополнения, Добродетели, Веры, Силы Воли или снижения постоянной Муки и записывает покупку в журнал.

### Броски

- Броски d10.
- Одиночные и комбинированные броски.
- Ручная сложность.
- Учет штрафов от здоровья.
- Поддержка логики `10 = 2 успеха` и `1 = -1 успех`.
- Чат-карточки бросков в читаемом стиле.
- Поисковые списки характеристик во встроенном конструкторе и диалогах.
- Подходящие Достоинства, Недостатки, активные формы и другие модификаторы предлагаются перед броском.
- Боевые броски поддерживают выбранную токен-цель, активную защиту, чистые успехи, урон, поглощение и применение результата.
- Панель состояний поддерживает оглушение, нокдаун, обездвиживание и другие общие эффекты.

### Дисциплины и силы

- Дисциплины.
- Силы дисциплин.
- Старшие уровни дисциплин.
- Светящиеся точки дисциплин.
- Карточки справки по дисциплинам.
- Карточки сил дисциплин.
- Поддержка редких дисциплин и линий крови, включая Демонизм, Шаманство, Полёт, Сангвинус, Бардо, Мельпомению, Танатозис, Мистерию, Обеах и Валерен.
- Автоматизированные карточки могут выполнять бросок, расходовать Кровь или Силу Воли и регистрировать длительный эффект.

### Demon: The Fallen

- Семь Домов падших с эмблемами и справочными данными.
- Группировки, Добродетели, Дополнения, Достоинства и Недостатки демонов.
- 26 Знаний и 130 Воззваний с описанием обычного и высокомучительного эффекта.
- 21 апокалиптическая форма и 168 механик обычных и высокомучительных способностей.
- Форма учитывает модификаторы бросков, инициативу, естественные атаки, броню, иммунитеты, дополнительные уровни здоровья и действия за Веру.
- Воззвания определяют запас броска, расход Веры, выбранную цель, встречное сопротивление, чистые успехи и длительность.
- Высокая Мука определяется по кубикам основного броска; тёмный вариант можно вызвать намеренно ценой временной Муки.
- Успешное Воззвание можно наложить на цель как активный эффект Foundry и впоследствии снять с листа.
- Структурированные договоры поддерживают условия, дары, ежедневное предложение Веры, включение, редактирование и разрыв.
- Жатва Веры выполняется встречным броском и публикует результат в чат.

### Мастера создания персонажа

Вампирский мастер помогает выбрать клан, Путь или Дорогу, стартовые характеристики и справочные сущности.

Демонский мастер проводит через Дом, группировку, Основное Знание, Атрибуты, Способности, Добродетели, Дополнения, Знания, Достоинства и Недостатки. Он считает стартовые и свободные очки, назначает начальную Муку и формирует апокалиптическую форму по Основному Знанию.

### Автоматический импорт справочников

При первом запуске мира GM-ом система автоматически импортирует встроенные справочники:

- кланы и линии крови;
- дисциплины;
- магия крови;
- ритуалы;
- оружие;
- достоинства и недостатки;
- дополнения;
- Пути и Дороги.

Повторный запуск не должен плодить дубли. Для этого используется служебная настройка мира `catalogSeedVersion`.

Ручной запуск автоимпорта:

```js
game.vtmRevised.seedBuiltInCatalogs()
```

Ручной импорт всех встроенных каталогов:

```js
game.vtmRevised.importBuiltInAllCatalogs()
```

Отдельные команды импорта:

```js
game.vtmRevised.importBuiltInCoreDisciplinesCatalog()
game.vtmRevised.importBuiltInBloodMagicCatalog()
game.vtmRevised.importBuiltInRitualCatalog()
game.vtmRevised.importBuiltInWeaponCatalog()
game.vtmRevised.importBuiltInClanCatalog()
game.vtmRevised.importBuiltInBackgroundCatalog()
game.vtmRevised.importBuiltInMeritsFlawsCatalog()
game.vtmRevised.importBuiltInMoralityCatalog()
```

## Разработка

### Проверка каталогов

```bash
npm run validate:catalogs
npm run check
npm test
npm run styles:build
npm run styles:check
npm run prerelease
```

Валидатор проверяет JSON-валидность каталогов, уникальность сущностей, связи кланов с дисциплинами, связи сил с родительскими дисциплинами, карточки Путей и Дорог, локализацию способностей, наличие файлов из `system.json`, предзагружаемые шаблоны и installable manifest. Общий тестовый сценарий дополнительно проверяет боевую математику, апокалиптические формы и механику Воззваний. Стили собираются из файлов `styles/source/`.


## Installable manifest

Foundry устанавливает систему через raw manifest:

```text
https://raw.githubusercontent.com/ercaslehon/vtm-revised-foundry-system/main/system.json
```

В `system.json` должны быть поля:

```json
{
  "url": "https://github.com/ercaslehon/vtm-revised-foundry-system",
  "manifest": "https://raw.githubusercontent.com/ercaslehon/vtm-revised-foundry-system/main/system.json",
  "download": "https://github.com/ercaslehon/vtm-revised-foundry-system/releases/download/v11.0.30/vtm-revised-v11.0.30.zip"
}
```

Ссылка вида `https://github.com/.../blob/main/system.json` не подходит. GitHub отдаёт HTML-страницу, а Foundry ждёт чистый JSON.

## Что не является целью проекта

Проект не претендует на официальный цифровой перенос всех книг Vampire: The Masquerade или Demon: The Fallen.

Справочники внутри системы являются игровыми выжимками, техническими карточками и удобными подсказками для домашнего использования. Для спорных правил, точных формулировок и официального текста следует обращаться к оригинальным книгам.
